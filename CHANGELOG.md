# Changelog

All notable changes to `vitalcentile` are documented in this file.

## 0.1.0 — 2026-08-11

### Added
- Official Python distribution name: `vitalcentile`.
- Simple `zscore()` convenience function using the official Centile API.
- `CentileClient` for configurable timeout, headers, and base URL.
- `centiles()` reference-curve helper.
- Research and evaluation license with mandatory attribution.

### Notes
- The public API currently supports the date-based `zscore()` workflow.
- The package is for non-commercial research and educational use only.
